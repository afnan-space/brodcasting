# 🚀 Telegram High-Speed Broadcaster (25 Users / Second)

এই প্যাকেজটি টেলিগ্রাম বট থেকে আপনার **Neon PostgreSQL** ডাটাবেজের সকল ইউজারের কাছে নিরাপদভাবে এবং সর্বোচ্চ গতিতে (প্রতি সেকেন্ডে ২৫টি মেসেজ) ব্রডকাস্ট পাঠানোর জন্য একটি প্রফেশনাল, সেলফ-কন্টেইন্ড পাইথন সল্যুশন।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- **নিরাপদ ও সর্বোচ্চ স্পিড (Strict 25 msg/s):** টেলিগ্রামের অফিসিয়াল লিমিটেশন মেনেই প্রতি সেকেন্ডে ঠিক ২৫ জন ইউজারকে মেসেজ পাঠায়, ফলে বট ৪২৯ (Flood Wait) খাওয়ার কোনো ঝুঁকি থাকে না।
- **নিওন ডাটাবেস ইন্টিগ্রেশন (Neon DB Streaming):** ডাটাবেজ থেকে মেমোরি ক্র্যাশ ছাড়াই ব্যাচ আকারে ইউজার আইডি কালেক্ট করে। ডিফল্টভাবে সর্বশেষ জয়েন করা ইউজাররা আগে মেসেজ পায় (`ORDER BY created_at DESC`)।
- **অটো ফ্লাড-ওয়েট রিকভারি (Flood Control Auto-Recovery):** কোনো কারণে টেলিগ্রাম সাময়িক ফ্লাড ওয়েট দিলে স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে প্রয়োজনীয় সময় পজ (Pause) হয়ে আবার নিজে থেকেই শুরু হয়।
- **ব্লকড ইউজার ফিল্টারিং:** যেসকল ইউজার বট ব্লক করেছে বা টেলিগ্রাম অ্যাকাউন্ট ডিলিট করেছে (`403 Forbidden`), তাদের আলাদা ফাইল `blocked_users.txt`-এ সেভ করে রাখে।
- **অটো রেজ্যুম / চেকপয়েন্ট (Resume Capability):** বিদ্যুৎ চলে গেলে, নেটওয়ার্ক ড্রপ হলে বা মাঝপথে স্ক্রিপ্ট বন্ধ করলে এটি `broadcast_state.json`-এ প্রগ্রেস সেভ রাখে। পরবর্তীতে রান করলে স্বয়ংক্রিয়ভাবে আগের জায়গা থেকেই শুরু করা যায় (কাউকে ডাবল মেসেজ যাবে না)।
- **ডায়নামিক পারসোনালাইজেশন:** মেসেজের ভেতরে `{first_name}`, `{username}`, `{id}` ট্যাগ ব্যবহার করে প্রত্যেক ইউজারের নাম স্বয়ংক্রিয়ভাবে বসানো যায়।
- **ফটো ও বাটন সাপোর্ট:** টেক্সটের পাশাপাশি ব্যানার ফটো এবং ইনলাইন ইউআরএল বাটন (যেমন: Mini App ওপেন বাটন) পাঠানো যায়।
- **ড্রাই-রান ও টেস্ট মোড:** আসল মেসেজ পাঠানোর আগে স্পিড ও লজিক সিমুলেট করার জন্য `--dry-run` মোড এবং নিজের আইডিতে প্রিভিউ দেখার জন্য `--test-user` অপশন।

## ⚙️ সেটআপ ও রান করার নিয়ম (How to Run)

pip install -r requirements.txt

### ধাপ ৩: স্ক্রিপ্ট রান করুন

#### পদ্ধতি ১: উইন্ডোজ ব্যাচ ফাইল দিয়ে (সবচেয়ে সহজ)
`run_broadcast.bat` ফাইলে ডাবল-ক্লিক করুন। একটি মেনু আসবে:
- **[1] Start Live Broadcast:** সরাসরি সব ইউজারের কাছে ২৫ msg/s স্পিডে পাঠানো শুরু করবে।
- **[2] Dry-Run Simulation:** কোনো মেসেজ না পাঠিয়ে ডেটাবেজ কানেকশন এবং স্পিড টেস্ট করবে।
- **[3] Send Test Message:** আপনার ব্যক্তিগত টেলিগ্রাম আইডিতে টেস্ট মেসেজ পাঠিয়ে প্রিভিউ দেখাবে।
- **[4] Resume Previous Broadcast:** আগের অসম্পূর্ণ ব্রডকাস্টের বাকিটুকু কন্টিনিউ করবে।

#### পদ্ধতি ২: কমান্ড লাইন দিয়ে (CLI Commands)

**১. নিজের আইডিতে একটি প্রিভিউ টেস্ট পাঠান:**
```bash
python broadcast.py --test-user 123456789
```

**২. ব্যানার ফটো এবং ইনলাইন বাটনসহ টেস্ট করতে:**
```bash
python broadcast.py --test-user 123456789 --photo-url "https://example.com/banner.jpg" --button-text "🤖 Open Mini App" --button-url "https://t.me/agentaiinvestdailybot"
```

**৩. ড্রাই-রান (সিমুলেশন) টেস্ট:**
```bash
python broadcast.py --dry-run --limit 100
```

**৪. লাইভ ব্রডকাস্ট শুরু করুন (২৫ ইউজার/সেকেন্ড):**
```bash
python broadcast.py --rate 25
```

**৫. ফটো এবং বাটনসহ লাইভ ব্রডকাস্ট শুরু করুন:**
```bash
python broadcast.py --rate 25 --photo-url "https://example.com/banner.jpg" --button-text "🚀 Open App" --button-url "https://t.me/agentaiinvestdailybot"
```

**৬. মাঝপথে বন্ধ হওয়া ব্রডকাস্ট রেজ্যুম করুন:**
```bash
python broadcast.py --rate 25 --resume
```

## ⚡ GitHub Actions দিয়ে ক্লাউডে ব্রডকাস্ট চালানোর নিয়ম

আপনার নিজের পিসি চালু না রেখে সরাসরি গিটহাব ক্লাউড সার্ভার (GitHub Actions) থেকে সম্পূর্ণ বিনামূল্যে ব্রডকাস্ট চালাতে পারবেন।

### ১. গিটহাব রিপোজিটরিতে Secrets সেটআপ করুন
আপনার গিটহাব রিপোজিটরিতে যান (`https://github.com/afnan-space/brodcasting`):
1. **Settings** ট্যাবে যান।
2. বাঁপাশের মেনু থেকে **Secrets and variables** -> **Actions** এ ক্লিক করুন।
3. **New repository secret** বাটনে ক্লিক করে নিচের সিক্রেটগুলো যোগ করুন:
   - `BOT_TOKEN`: আপনার মূল টেলিগ্রাম বট টোকেন (যেটি দিয়ে মেসেজ পাঠানো হবে)
   - `DATABASE_URL`: আপনার Neon PostgreSQL কানেকশন ইউআরএল
   - `ADMIN_USER_ID`: আপনার টেলিগ্রাম আইডি (যেমন: `8509322025`)
   - `ADMIN_BOT_TOKEN`: (ঐচ্ছিক) কন্ট্রোল বটের টোকেন

### ২. গিটহাবে কোড পুশ করার কমান্ড
টার্মিনালে এই ফোল্ডারে এসে রান করুন:
```bash
git init
git branch -M main
git remote add origin https://github.com/afnan-space/brodcasting.git
git add .
git commit -m "Add GitHub Actions workflow for broadcasting"
git push -u origin main
```
*(দ্রষ্টব্য: `.gitignore` ফাইল থাকায় আপনার `.env` এবং গোপন ডাটাবেজ পাসওয়ার্ড কখনোই গিটহাবে আপলোড হবে না)*

### ৩. যেভাবে ব্রডকাস্ট রান করবেন
1. গিটহাবে আপনার রিপোজিটরির **Actions** ট্যাবে যান।
2. বাঁপাশে **🚀 Telegram Bulk Broadcaster** সিলেক্ট করুন।
3. ডানপাশে **Run workflow** বাটনে ক্লিক করুন।
4. অপশনগুলো পছন্দমতো দিন:
   - **Execution Mode**: `live` (সরাসরি মেসেজ পাঠাতে), `dry-run` (টেস্ট রান), অথবা `test` (শুধু নিজের আইডিতে প্রিভিউ দেখতে)।
   - **Custom Message**: চাইলে এখানে নতুন কোনো মেসেজ লিখতে পারেন, অথবা খালি রাখলে `message_template.txt` ফাইলটি পাঠাবে।
   - **Banner Image URL**: চাইলে ফটো ব্যানার দিতে পারেন।
   - **Button Text & URL**: চাইলে ইনলাইন বাটন দিতে পারেন।
   - **Rate**: ডিফল্ট `25` msg/s।
   - **Resume**: আগে কোনো ব্রডকাস্ট মাঝপথে বন্ধ হয়ে থাকলে রেজ্যুম করতে ট্রু করুন।
5. সবুজ **Run workflow** বাটনে চাপুন!

ব্রডকাস্ট শেষ হলে **Summary** পেজে স্বয়ংক্রিয়ভাবে মোট কতটি পাঠানো হয়েছে, কতজন ব্লক করেছে তার হিসাব এবং সম্পূর্ণ লগ ও রিপোর্ট ডাউনলোড করার অপশন দেখতে পাবেন।
